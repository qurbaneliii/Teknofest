PHASE 3 — BIVARIATE ANALYSIS: FEATURES vs LABEL
════════════════════════════════════════════════════════════
═══════════════
3.1 For every numeric feature (raw AL, EK, and any engineered aggregate),
compute a single-feature separation metric vs Label:
- Mann-Whitney U test → convert to AUC-equivalent (rank-biserial)
- Report p-value and effect size
- Rank ALL numeric features by this AUC and present the top 25 and
bottom 25 in a table
3.2 For every categorical feature, compute Label rate per category
(group-by mean) with category counts, sorted by Label rate. Flag any
category whose Label rate deviates by more than 20 percentage points
from the dataset-wide base rate.
3.3 Investigate missingness AS a feature: for every column with partial
missingness, compute the correlation (or mean Label difference) between
"is this value missing" and Label. Report the columns where missingness
itself is most predictive — this is a strong signal in ACMG-style data
(absence from a population database can itself indicate rarity).
3.4 Produce box plots or violin plots of the top 10 most separating numeric
features, split by Label.
